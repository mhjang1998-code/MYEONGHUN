# 영어 복습 앱 – 발음 듣기 (기기 음성)

## 적용 (Apps Script 편집기)
1. `StudyPage.html` → 이 저장소의 `StudyPage.html` 내용으로 **전체 교체** → 저장
2. 배포 → 배포 관리 → 수정(연필) → 버전 **새 버전** → 배포

`.gs` 파일은 바꾸지 않습니다. 단어·복습 기록·필터 저장 방식도 그대로입니다.

## 동작
| 항목 | 동작 |
|---|---|
| 기본 발음 | 미국식 (en-US) |
| 목소리 목록 | 그 기기의 남성 음성만, 최대 3개 (자연스러운 음성 우선) |
| 남성 음성이 없을 때 | 다른 음성으로 바꾸지 않고 "사용 가능한 미국식 남성 음성이 없습니다" 안내 |
| 저장 | 억양·목소리·속도는 구글 계정에 저장 → 다음에 열어도 유지 |
| 다른 기기에서 고른 목소리 | 이 기기에 없으면 이 기기의 남성 음성으로 읽음 (설정은 지우지 않음) |
| 5회 반복 | 회차 사이 0.5초, 다른 동작을 하면 즉시 중단 |

## 기기 음성의 한계
- 웹페이지는 **기기에 설치된 목소리만** 쓸 수 있고, 목소리를 설치해 줄 수 없습니다.
- 브라우저는 목소리의 성별 정보를 주지 않습니다. 그래서 **이름**(Guy, David, Aaron, Evan 등)으로 남성 음성을 찾습니다. 이름이 목록에 없는 남성 음성은 빠질 수 있습니다.
- 아이폰·아이패드: 설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성 → 영어(미국) → 남성 음성(Aaron, Evan, Nathan, Tom 등) 다운로드. 내려받은 목소리가 Safari에서 보이지 않는 iOS 버전도 있습니다.
- Windows: Edge에서는 Guy·Christopher 같은 자연스러운 음성이 나옵니다. Chrome에서는 David·Mark처럼 음질이 낮은 음성이 나옵니다.
- 기기마다 목소리가 달라 **완전히 같은 목소리로 통일할 수는 없습니다.**

## 테스트
```
npm install && npm test
```
가짜 음성 목록(Windows 음성 / 남성 음성 없는 아이폰)으로 목록, 대체 금지, 반복 간격, 취소, 설정 저장을 확인합니다.
