4 · 선형 회귀 + Ridge / Lasso (김현우)

Ridge·Lasso는 선형 회귀에 벌점을 줘 닮은 변수를 정리한다

선형 회귀 = 변수마다 기울기(계수)를 곱해 더하기. 초기 조건 변수끼리 너무 닮으면 계수가 불안정해서 벌점으로 줄이거나 0으로 만든다

선형 회귀 · Ridge · Lassolinear regression · Ridge (L2) · Lasso (L1)[리니어 리그레션 · 릿지 · 라소] NH₃ = a×Day + b×온도 + c×TN0 + … Ridge는 계수²의 합에 벌점(골고루 줄임), Lasso는 |계수|의 합에 벌점(필요 없는 계수를 0으로).

Ridge = 골고루 줄임 (L2), Lasso = 필요 없는 변수를 0으로 (L1)

우리 데이터에서는 처리구를 하나씩 빼고 맞혀 보니 R²가 모두 0보다 낮다. 직선으로는 Day 1~4의 NH₃ 정점과 뒤의 감소를 함께 그릴 수 없다.

우리 캡스톤에서는선형·Ridge를 “기준선 모델”로 꼭 돌린다
  • 나무 모델이 이 기준선보다 나아야 의미가 있다 (회의: Ridge·SVR·로그 모델 추가)
  • Lasso로 닮은 초기 조건 중 대표 변수를 고른다
