R²가 실제로 계산하는 것

R² = 1 − (예측 오차²의 합) ÷ (평균에서 벗어난 정도²의 합)

“그냥 평균값만 찍었을 때”보다 오차를 얼마나 줄였는가. 0.937이면 GI 변동의 93.7%를 설명했다는 뜻이다.

둘이 같아지는 유일한 경우

변수 하나로 직선을 그어 예측할 때만 R² = r².
예: 기간↔GI r = 0.75 → 0.75² ≈ 0.56. 기간 하나로는 GI의 56%만 설명된다. 7개 변수를 쓴 RF는 0.937까지 올렸다.

읽을 때 주의. Wang 논문의 “R² > 90%”는 R² > 0.90으로 읽는다. 시험 데이터에서는 평균보다 못 맞히면 R²가 음수도 나온다.

발표 메모 · 공부하며 나온 질문

  1. Q. 피어슨 상관계수 값이 R² 값인가? → 아니다. r은 변수끼리의 관계(전처리), R²는 모델 성적(평가).
  2. “항상 +25 높게 예측” 버튼으로 시연: r은 거의 1인데 R²는 크게 떨어진다. r은 같이 움직이는지만, R²는 맞혔는지를 본다.
  3. R² = r²는 변수 하나로 직선 회귀할 때만 성립. 기간↔GI 0.75² ≈ 0.56.
  4. 실제 값: Shi RF 시험 R² 0.937 (RMSE 7.261), Wang XGB NH₃ 시험 R² 0.966, GWP 0.912.
