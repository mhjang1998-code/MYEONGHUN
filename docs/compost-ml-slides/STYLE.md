# HTML 발표 자료 규칙 (페이퍼로지 스타일)

모든 HTML 발표 자료(이 폴더와 앞으로 만들 자료)는 이 규칙을 따른다.
원본 가이드: [HTML_PPT_GUIDE.txt](HTML_PPT_GUIDE.txt) (특히 P1 마스터 프롬프트, P5 수정 체크리스트).

## 작업 방식
- 질문 하나 = 장표 하나. `slides/NN-이름.html` 조각 파일로 만든다.
- `python3 build_deck.py` → `deck.html` 한 파일로 합쳐진다 (폰트 subset 내장, 오프라인 동작).
- 게시: Artifact `deck.html` (같은 경로로 다시 게시하면 같은 링크 유지).
  현재 링크: https://claude.ai/artifact/QwmmjgJReMtfNT5rheYwV7

## 무대·그리드 (모든 장 같은 위치)
- 1920×1080 고정 무대, 창 크기에 맞춰 scale, 레터박스 #161C20, 스크롤 없음.
- 좌우 여백 86px · 섹션명 top 62 / 28px / 700 / 메인블루 · 헤드라인 top 116 / 48px / 700 / 한 줄, 결론 문장(36자 이내)
- 서브타이틀 top 223 / 24px / 700 (65자 이내) · 본문 top 279 ~ 하단 110 · 주석 하단 66 / 18px · 푸터 하단 24 (출처 | 쪽번호)
- 2단: 왼쪽 본문 1060px + 오른쪽 사이드 패널 (x 1210, 폭 624, #EAEEF8, 큰 숫자 92px + 단위 32px)
- 본문 글자 최소 18px, 보통 20px. `word-break: keep-all`, 숫자 `tabular-nums`.

## 색 (이 외 금지)
메인 #002FA7 · 단계 #4D6DC1 #99ACDB #D9E0F2 · 패널 #EAEEF8 · 진한 글자 #001C64 · 본문 #222 · 주석 #6B7C85 · 선 #D0D6DE · 회색 #B7BDC5 #EEF0F2.
오렌지 #FF7A00은 포커스·선택 표시에만. 흰 배경. 둥근 모서리·그림자·장식 그라데이션·이모지 금지 (색 범례 막대는 예외).

## 폰트
Pretendard 400/500/700만. `assets/fonts`의 woff2를 빌드가 subset해서 base64로 내장한다.

## 쉽게 (청중: ML을 처음 듣는 학부생)
- 화면에는 **용어 카드 1개 + 쉬운 말 한 문장 + 버튼 하나짜리 시연**만 둔다. 공식·표·세부 설명은 서랍으로.
- 용어 카드(`.term`): 한글 · English · [발음] · 쉬운 뜻 한 줄(가능하면 일상 비유).
- 서랍 “내역”에 그 장의 용어표(용어 | 영어 [발음] | 쉬운 뜻)를 둔다.
- 사이드 패널: 「외울 한 줄」(`.memo`) → “논문에서는” 한 문장(`.p2`) → 「우리 캡스톤에서는」 박스(`.insight`).
- 설명 순서: 일상 비유 → 퇴비 예시 → 논문 문장. 사용자는 퇴비화 도메인은 강하고 ML은 처음 배우는 단계.
- 새 용어는 반드시 암기 카드 장(`95-flashcards.html`)과 정리 장(`90-summary.html`)에도 추가한다.

## 장 구성
- 한 장에 메시지 하나. 화면 글은 짧게, 자세한 표·전제·출처는 서랍(`<template data-tab="detail|source|notes">`).
- 숫자는 차트, 과정은 단계 카드, 비교는 표. 직접 조작하는 시연(슬라이더·토글)을 장마다 하나.
- 공부하며 나온 질문은 그 장의 “발표 메모” 탭에 기록한다.
- **모든 장 사이드 패널 하단에 「캡스톤 인사이트」 박스**(`.insight`)를 같은 자리에 둔다: 이 내용으로 우리 문헌 기반 데이터를 넣을지·버릴지·어떻게 가공할지, 결정 1줄 + 근거 2줄.
- 장 순서는 캡스톤 파이프라인: ① 전처리 → ② 모델 → ③ 평가 → ④ 해석. 섹션명 앞에 단계 번호를 붙인다.
- 파일 이름 번호는 10 단위(10, 20, …)로 매겨 사이에 새 장을 끼울 수 있게 한다.

## 모션·조작
- 요소 순차 등장(`.rv` + `--d` 지연), 막대 성장(`.grow`), 페이지 페이드 0.45s. `#static`·동작 줄이기면 끔.
- ←/→/Space/PageUp/PageDown, 숫자키, O 쪽 목록, N 발표 메모, Esc 닫기, `#3` 해시로 특정 장.

## 정직성
- 논문에 없는 수치·출처를 만들지 않는다. 읽지 못한 값은 생략하고 “값 생략”으로 표시.
- 설명용 숫자는 화면 주석과 서랍에 “예시 데이터 · 입력에 따른 계산”이라고 적는다.

## 완료 전 점검
- 1366×768에서 모든 장 헤드라인 한 줄, 본문 넘침 없음, 콘솔 에러 없음 (Playwright로 확인).
- 차트 막대 길이와 라벨 숫자 일치. 확인하지 못한 항목은 “확인 못 함”으로 보고.
