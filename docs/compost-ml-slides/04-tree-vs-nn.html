트리는 순서를 보고, 신경망·KNN은 크기를 본다

그래서 표준화가 꼭 필요한 모델과 거의 상관없는 모델이 갈린다. 온도 단위를 바꿔 보며 트리의 기준선이 어떻게 움직이는지 보자.

결정 트리의 질문 하나: “온도가 기준보다 높은가?”

트리 (RF·XGB)기준선으로 나누기만 한다단위 바꿔도 결과 같음
KNN변수 차이로 거리를 잰다숫자 큰 변수가 독차지
신경망 (BPNN·MLP)입력 × 가중치 → S자 곡선큰 값이면 포화
점: 설명용 예시 퇴비 8개. 초록 = 부숙, 주황 = 미부숙. 고온기 퇴비일수록 아직 덜 익은 경우가 많다.
