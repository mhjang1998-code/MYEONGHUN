② 모델 · 지도학습 · 회귀 · 분류

지도학습은 정답이 달린 문제집으로 공부하는 것이다

숫자를 맞히면 “회귀”, 종류(부숙/미부숙)를 맞히면 “분류”. 두 논문 모두 지도학습이다

지도학습supervised learning[수퍼바이즈드 러닝] 입력(기간·온도·C/N …)과 정답(NH₃ 배출량, 부숙 여부)이 짝지어진 데이터로, 입력 → 정답 규칙을 배우는 방법. 선생님(정답)이 있다.
입력 X
기간·온도·C/N·함수율→모델→예측⇄정답 y
(문헌에서 잰 값)→ 틀린 만큼 고치며 배움
외울 한 줄
지도학습 = 정답 있는 데이터로 배우기. 숫자면 회귀, 종류면 분류

논문에서는 Wang: XGB로 “지도학습 회귀 모델”을 만들어 NH₃·GWP 숫자를 예측하고, KNN으로 부숙 여부를 분류했다.

우리 캡스톤에서는정답 열(맞힐 값)부터 정한다
  • NH₃ 배출량처럼 숫자면 회귀 → R²·RMSE로 평가
  • 부숙 여부처럼 종류면 분류 → 정확도로 평가
Wang 2024: NH₃·GWP = 회귀(XGB·RF), 부숙 여부 = 분류(KNN, GI > 80%면 부숙) · Shi 2025: GI = 회귀
