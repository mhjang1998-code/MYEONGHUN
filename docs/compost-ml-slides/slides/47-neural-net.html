② 모델 · 신경망과 활성화 함수

신경망은 숫자를 더한 뒤 밝기 조절기로 신호를 만든다

밝기 조절기를 너무 세게 돌리면 최대 밝기에서 멈춘다. 그러면 더 돌려도 변화가 없어 배울 수 없다(포화)

신경망neural network[뉴럴 네트워크]입력 × 가중치를 더하고(①) 신호로 바꾸는(②) 계산을 여러 층 쌓은 모델
활성화 함수activation function[액티베이션 펑션]더한 값을 0~1 신호로 바꾸는 밝기 조절기 (S자 곡선)

퇴비 A (pH 6.0, NH₄⁺ 1,200)를 뉴런 하나에 넣고 학습시켜 보기 · 정답은 “미부숙 = 0”

학습 횟수가중합 z출력 y기울기 (학습 신호)방금 가중치 변화

활성화 함수 = 밝기 조절기. 값이 너무 크면 끝에 붙어(포화) 학습이 멈춘다

논문에서는 Shi의 신경망 BPNN 시험 R² 0.616, MLP 0.664. 데이터 184개로는 나무 모델(RF 0.937)보다 약했다.

  • 원래 값 그대로 넣으면 포화되어 학습이 멈춘다
  • 문헌 데이터 수백 개 규모에선 신경망이 불리 → 트리를 기본, 신경망은 비교용
