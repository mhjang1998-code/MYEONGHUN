키와 몸무게는 거의 같이 움직인다(r ≈ 0.9). 둘 다 넣어도 정보는 사실상 하나라서, 모델이 “진짜 원인이 뭐지?” 하고 헷갈린다.

논문 결과: 입력 변수끼리 |r| = 0.2~0.4로 약했다 → 각 변수가 서로 다른 정보를 가져온다 → 8개 변수를 모두 넣어도 된다.

주의. 피어슨은 직선 관계만 잡는다. 통기량처럼 “너무 많아도, 너무 적어도 NH₃가 줄어드는” 곡선 관계는 r이 0 근처로 나온다. 그래서 r만 보고 변수를 버리지 않고, 실제 영향은 나중에 SHAP으로 다시 확인했다.

발표 메모 · 공부하며 나온 질문

  1. Q. “PCC 절댓값 0.2~0.4라서 중복이 없다”는 게 무슨 뜻? → 입력 변수끼리 서로 닮지 않았다는 뜻. 겹치는 정보가 없으니 모두 넣어도 된다.
  2. 문장이 “입력↔출력 관계 파악”으로 시작하지만, 0.2~0.4 결론은 입력↔입력 중복 이야기다. 두 목적을 나눠서 말하기.
  3. 예외: 시간은 다른 변수와 상관이 높지만 뺄 수 없다. 퇴비화의 진행 자체를 나타내는 핵심 변수이기 때문 (Wang 3.1).
  4. “곡선 관계” 버튼으로 r의 한계를 보여 주고 SHAP 슬라이드로 연결.
